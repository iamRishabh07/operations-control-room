---
name: brief-audit
description: Translate a take-home exercise brief into a traceable acceptance matrix without writing application code. Use when analyzing or clarifying the Uber requirements.
---

1. Read `docs/assignment-brief.md` and the source PDF when possible.
2. List mandatory, optional, out-of-scope requirements.
3. Build a requirement -> planned implementation -> proof/test table.
4. Identify ambiguous assumptions and default to the smallest satisfying interpretation.
5. Recommend no implementation until the user approves a plan.
