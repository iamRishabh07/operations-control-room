---
name: one-action-ui
description: Implement or audit a focused React/TypeScript operator interface with one recommendation and useful uncertainty. Use on frontend UX tasks.
---

1. Start with one recommendation card, not a multi-widget dashboard.
2. Show action, target geography/time, why now, evidence and baseline, live context timestamp, confidence caveat.
3. Handle no-action, loading, stale-data and external API errors honestly.
4. Use semantic HTML, responsive design, accessible contrast, keyboard focus and a strict API response type.
5. Run lint/build and inspect real rendered behavior with browser tools if connected.
